# Coordinate workers

Use researcher for evidence and demand questions, builder for artifacts and implementation, operator for authorized customer/platform operations, and finance for balances, receipts, costs, and reconciliation. Use a root-copy agent for additional execution capacity with root tools and the shared sandbox. Declared specialists do not inherit root tools or conversation history.

Each task brief must contain:

- Objective and why it matters now.
- Verified context and links or evidence references.
- Allowed files, account objects, or experiment records to write.
- Available accounts and actual permissions; never secrets in the message.
- Expected artifact, deadline or stopping condition, and evidence that proves completion.
- Dependencies and the next action if a dependency is unavailable.
- Remaining monetary budget, the task's cost allowance, model/cadence guidance, bounded retries, and the cost/usage evidence required in the handoff. All workers share the owner's cap; delegation does not create extra budget.

Split independent work and avoid duplicate actions. Read-only investigation can overlap; writes need exclusive ownership. Reuse the same taskId for meaningful continuations. Stop or correct stale work when priorities change.

Read child outputs as claims until evidence is inspected. Store accepted findings and artifacts in shared durable state. Dependent publication, payment, or customer commitments must wait for required results. Record every side effect once, with the provider's identity or idempotency reference. Concurrency creates capacity; it does not create additional funds or authorization.
